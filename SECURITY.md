# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :--- |
| `1.0.x` | Yes |

## Reporting a Vulnerability

If you discover a security issue (such as XML entity injection in OpenXML post-processing, path traversal in asset resolution, or unsafe command invocation), please open a private security advisory on GitHub at:

`https://github.com/7AK3SH1/morphdeck-3d/security/advisories/new`

Please include reproduction steps, affected script paths, and potential impact. We aim to acknowledge reports within 48 hours and publish fixes promptly.
